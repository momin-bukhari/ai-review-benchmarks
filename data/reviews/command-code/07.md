# Review: Index pending deliveries

This is a clean, well-targeted change. The partial index:

```sql
CREATE INDEX deliveries_due_by_queue ON deliveries (queue, scheduled_at, id)
WHERE delivered_at IS NULL;
```

matches the worker query pattern in `deliver_due()`:
```sql
SELECT id FROM deliveries WHERE queue = ? AND delivered_at IS NULL
AND scheduled_at <= ? ORDER BY scheduled_at, id
```

The index columns `(queue, scheduled_at, id)` cover the equality filter on `queue`, the range filter on `scheduled_at`, and the ORDER BY tiebreaker on `id`. The partial index condition `WHERE delivered_at IS NULL` keeps the index small by excluding already-delivered rows.

No concerns with this change.
