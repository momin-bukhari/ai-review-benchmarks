# Review: Include a total in the activity summary

This is a straightforward additive change. Adding `"total": sent + waiting` to the summary response is consistent — the total equals delivered + pending, which is the full row count.

The computation is derived from the same query that already produces `sent` and `waiting`, so there's no additional database cost. The total is logically correct: `count(delivered_at) + (count(*) - count(delivered_at)) = count(*)`.

No concerns with this change.
